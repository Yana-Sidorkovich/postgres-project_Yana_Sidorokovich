# Task 2: BoM Explosion

## Описание
Раскрытие иерархии спецификации (Bill of Material) для производственных материалов.
Цепочка: FIN (готовая продукция) → PROD (полуфабрикаты) → ADD/RM (компоненты)

## Структура решения

### Pandas (Pandas_Task2_Final.ipynb)
- Загрузка Excel, очистка данных
- Построение иерархии через 4 последовательных merge
- Добавление количеств через словари-индексы
- Результат: 80 уникальных связей BoM
- Сохранено в: data/bom_exploded_result.xlsx

### SQL (bom_sql_script.sql)
- Таблица bom_raw: 1320 строк (сырые данные с дубликатами по месяцам)
- Таблица bom_unique: 110 уникальных структурных связей
- VIEW bom_exploded_view: рекурсивный CTE, 100 строк
- СУБД: PostgreSQL

## Примечания
- В исходных данных только 2024 год (2025 отсутствует)
- Разница Pandas (80) vs SQL (100): Pandas версия брала только 3 уровня 
  иерархии через merge, SQL через рекурсивный CTE показывает все 4 уровня 
  корректно. SQL версия является более полной.
